# UrbanNav Benchmark Inputs

This folder contains observations, cleaned broadcast navigation data and reusable GPS inputs. It does not include the teaching team's scoring reference.

| File | Purpose |
| --- | --- |
| `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs` | 1534 observation epochs, GPS week 2158 |
| `UrbanNav_20210521_multiGNSS_clean.nav` | Matching multi-constellation broadcast navigation |
| `preprocessed_gps/` | GPS L1 inputs generated by the included MATLAB converter for the Python solver |

See the root `Readme.md` for a quick start. The NAV includes multiple constellations, but the baseline uses GPS only. Failed epochs are kept as NaN during conversion, omitted by Python and recorded in the output. Do not use the 2025 example NAV with these 2021 observations. See [data sources](../docs/data_sources.md) for provenance and cleaning details.
