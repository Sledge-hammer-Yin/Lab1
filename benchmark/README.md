# UrbanNav Benchmark Inputs

This folder contains observations, cleaned broadcast navigation data and reusable GPS inputs. The teaching team's scoring reference is not included.

| File | Purpose |
| --- | --- |
| `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs` | 1,534 observation epochs, GPS week 2158 |
| `UrbanNav_20210521_multiGNSS_clean.nav` | Multi-constellation broadcast navigation data for the same date |
| `preprocessed_gps/` | GPS L1 inputs generated by this package's MATLAB function for direct use by Python |

See the root `Readme.md` for a quick start. The navigation file contains multiple constellations, but this baseline uses GPS only. Preprocessing leaves failed epochs as NaN; Python omits them and records the reasons. Do not use the example NAV from a different year with the 2021 OBS.

See [data sources](../docs/data_sources.md) for provenance and cleaning details.
