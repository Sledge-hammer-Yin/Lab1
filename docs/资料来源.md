# 数据与代码来源

## 配套历史示例

来自用户已下载的 `AAE4203-lab`，原项目地址：
[Gao-tech1/AAE4203-lab](https://github.com/Gao-tech1/AAE4203-lab)。

- UBX 来自原目录根部的 `COM6___9600_250916_020025_blockz.ubx`。
- 示例 OBS/NAV、五个输入 CSV、接收机参考、POS/KML 及保存的结果来自原目录的 `dataset/`。
- 原目录根部另一套4548历元 CSV 没有混入本包。
- 示例记录时间：2025-09-16 02:00:54.006 至02:03:59.006 GPST，共186历元。
- `epochs.csv` 从对应 OBS 提取，未从行号或人工日期推算。提交时按0.1秒网格输出。
- `reference_results/` 中保留原作者结果；数值复现不代表对原算法的所有物理模型作独立认证。
- 旧 CSV 没有卫星ID或星座标签，不在本说明中将其断言为纯GPS。

Python 原算法的6个数值函数抽取到 `tools/legacy_solver.py`，函数内容保留；根目录入口增加参数、时间匹配、数据检查和输出隔离。
原始脚本单独放在 `legacy/`，便于核对修改。

## UrbanNav 基准

[UrbanNav 官方项目](https://github.com/IPNL-POLYU/UrbanNavDataset#urbannav-hk-deep-urban-1)。

- `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs`：来自用户已有的 `Data/`，1534历元。
- GPST：2021-05-21 06:29:06.004 至06:54:39.005，GPS周2158。
- 原项目公开真值，但本教学包不分发或读取教师评分用的 `UrbanNav_whampoa_raw.txt`。
- 本包的输出仍需教师评分系统评估；不能将该公开数据集表述为严格保密的测试集。

## 导航文件

基准 NAV 不是上述2025年示例 NAV。它由香港地政总署 HK SatRef 2021年第141天 HKSC 的 GPS、GLONASS、Galileo、BeiDou 广播导航记录合并清理。

来源说明：[HK SatRef RINEX 下载](https://www.geodetic.gov.hk/en/rinex/ftp_RINEX.htm)。

本包 `UrbanNav_20210521_multiGNSS_clean.nav` 复制自本地验证目录中实际命名为 `UrbanNav_20210521_multiGNSS.nav` 的清理版。
其 SHA256 与既有验证记录中的 clean 版本一致：

```text
38c83f4007aab06a88074591054d511a4b132c2798ad90d85d7ead4bfca7cf88
```

清理包括去掉异常空白行、统一LF换行、保留一条GPS基准的18秒闰秒记录；未重新拟合或修改广播轨道数值。
NAV 含多个星座，不表示本包 GPS 基线已实现多星座解算。

`benchmark/preprocessed_gps/` 由本包 `rinex2csv.m` 从本包 OBS/NAV 实际生成。
生成设置和原始输入哈希记录在该目录的 `manifest.json`。
