# Data and Code Sources

## Historical example

The example comes from the downloaded [Gao-tech1/AAE4203-lab](https://github.com/Gao-tech1/AAE4203-lab) repository.

- The UBX file comes from its root. The OBS/NAV, five input CSV files, receiver reference, POS/KML files and saved results come from its `dataset/` directory.
- The separate 4,548-epoch CSV files in the original root were not mixed into this package.
- The example covers 2025-09-16 02:00:54.006 to 02:03:59.006 GPST: 186 epochs.
- `epochs.csv` comes from the matching OBS, not from row numbers or guessed dates. Submission times use a 0.1-second grid.
- `reference_results/` preserves the original author's results. Reproducing them does not independently validate every physical model.
- The original CSV files lack satellite IDs and constellation labels; they are not asserted to be GPS-only here.

Six numerical functions from the original Python algorithm are retained in `tools/legacy_solver.py`. The root entry point adds arguments, time matching, checks and separate output folders. Original scripts are also in `legacy/`.

## UrbanNav benchmark

[UrbanNav official project](https://github.com/IPNL-POLYU/UrbanNavDataset#urbannav-hk-deep-urban-1)

- `UrbanNav-HK-Deep-Urban-1.ublox.f9p.obs` comes from the user's existing `Data/` and contains 1,534 epochs.
- GPST: 2021-05-21 06:29:06.004 to 06:54:39.005, GPS week 2158.
- UrbanNav publishes ground truth, but this package neither distributes nor reads the teaching team's scoring reference `UrbanNav_whampoa_raw.txt`.
- The teacher's scoring system must still evaluate outputs. The public dataset is not a strictly confidential test set.

## Navigation file

The benchmark NAV differs from the 2025 example NAV. It merges cleaned GPS, GLONASS, Galileo and BeiDou broadcast navigation records for HKSC, day 141 of 2021, from [HK SatRef RINEX](https://www.geodetic.gov.hk/en/rinex/ftp_RINEX.htm).

`UrbanNav_20210521_multiGNSS_clean.nav` was copied from a validated local clean file named `UrbanNav_20210521_multiGNSS.nav`. Its recorded SHA256 is:

```text
38c83f4007aab06a88074591054d511a4b132c2798ad90d85d7ead4bfca7cf88
```

Cleaning removed abnormal blank lines, standardised LF line endings and retained one GPS reference leap-second record of 18 seconds. It did not refit or change broadcast orbit values. Although the NAV has multiple constellations, the supplied baseline solves GPS only.

`benchmark/preprocessed_gps/` was generated by this package's `rinex2csv.m` from the included OBS/NAV. Its `manifest.json` records settings and input hashes.

## Third-party code and course documents

- The original teaching code retains GAO Yixin's 2025 MIT `LICENSE`.
- [MatRTKLIB](https://github.com/taroz/MatRTKLIB) retains the course repository's complete folder, author notes and license. Its original `+gt/` CSV files remain; the runnable entry point uses explicit input folders instead.
- The local CSV checker validates five columns, three-decimal coordinates, finite values, order, duplicate epochs and observation-time coverage, along with course filenames and Earth-surface bounds. It is not the online scoring server.
- The server parser used for format comparison was `PolyU-TASLAB/AAE4203_ASN_2026/app/submission.py`, blob SHA `facc63595de9a46bc76deb2cbe8fccb8686a07fc`. Its source is not copied into this package.
- Original course versions of the converter and checker are in `legacy/rinex2csv_course_original.m` and `legacy/check_submission_course_original.py`.
- The report template is copied byte for byte from the course version. Follow the tutorial and Blackboard for current requirements.
- The two teaching PDFs came from course repository commit `ead5920dd0561d2beaf9ca2c15a899b337d825d1`. The original checked versions had 30 and 55 pages, respectively, and were not rewritten at that time. No eight-digit student ID followed by a letter was found in their extracted text. Source DOCX/PPTX files containing actual student lists were not included in that public candidate package.
- The recorded Git blob SHA1 values for those checked PDF versions were `0af22222af693623763f21eeca935083fe4dfc07` for the tutorial and `6590b36a3635963f115590309d93245e27efad80` for the slides.
- The code license does not grant additional rights to UrbanNav, HK SatRef data or course documents. Follow their own terms and retain attribution.
