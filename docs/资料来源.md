# Data and Code Sources

## Historical example

The example comes from [Gao-tech1/AAE4203-lab](https://github.com/Gao-tech1/AAE4203-lab). The root UBX file and the matching OBS/NAV, five measurement CSVs, receiver reference, POS/KML and saved results in `dataset/` come from that source. A separate 4548-epoch CSV set from its root was not included.

The example contains 186 epochs from 2025-09-16 02:00:54.006 to 02:03:59.006 GPST. `epochs.csv` comes from the matching OBS and submission times use a 0.1-second grid. `reference_results/` retains the original author's results; numerical reproduction is not independent validation of every physical model. The old CSVs have no satellite or constellation labels, so they are not claimed to be GPS-only.

Six original numerical functions are retained in `tools/legacy_solver.py`. The root Python entry adds parameters, time matching, input checks and separate output paths. Original scripts are also in `legacy/`.

## UrbanNav benchmark and navigation data

The 1534-epoch OBS comes from [UrbanNav HK Deep Urban 1](https://github.com/IPNL-POLYU/UrbanNavDataset#urbannav-hk-deep-urban-1): 2021-05-21 06:29:06.004 to 06:54:39.005 GPST, GPS week 2158. The original project publishes ground truth, but this package does not distribute or read the teaching scoring reference `UrbanNav_whampoa_raw.txt`. The scoring system must evaluate submitted results; this public dataset is not a strictly secret test set.

The benchmark NAV differs from the 2025 example NAV. It merges and cleans GPS, GLONASS, Galileo and BeiDou broadcasts from HKSC, day 141 of 2021, obtained from [HK SatRef](https://www.geodetic.gov.hk/en/rinex/ftp_RINEX.htm). The included `UrbanNav_20210521_multiGNSS_clean.nav` matches the previously verified clean file, SHA256:

```text
38c83f4007aab06a88074591054d511a4b132c2798ad90d85d7ead4bfca7cf88
```

Cleaning removed abnormal blank lines, normalized LF endings and retained one GPS 18-second leap-second record; broadcast orbital values were not refitted or changed. Multi-constellation NAV does not mean the provided GPS baseline solves multiple constellations. `benchmark/preprocessed_gps/` was generated by the included `rinex2csv.m` from the supplied OBS/NAV; its `manifest.json` records settings and hashes.

## Third-party code and course documents

- The original teaching code retains GAO Yixin's 2025 MIT `LICENSE`.
- [MatRTKLIB](https://github.com/taroz/MatRTKLIB), its authorship, license and original toolbox CSV files are retained. The runnable entry uses explicit input directories.
- The CSV checker validates the five-column format, three-decimal coordinates, finite values, order, duplicates and observed-epoch coverage, as well as course filenames and Earth-surface bounds. It is not the scoring server. Its comparison used `PolyU-TASLAB/AAE4203_ASN_2026/app/submission.py`, blob `facc63595de9a46bc76deb2cbe8fccb8686a07fc`.
- Original course scripts remain in `legacy/rinex2csv_course_original.m` and `legacy/check_submission_course_original.py`.
- The report template and course requirements are governed by the tutorial and Blackboard. The original course PDFs came from commit `ead5920dd0561d2beaf9ca2c15a899b337d825d1`; the current 30-page tutorial and 57-slide PDF were subsequently updated with repository links.
